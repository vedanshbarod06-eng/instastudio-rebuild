# InstaStudio rebuild
Login-free installable PWA prototype, separate from Orbit Social and not connected to Instagram or the original app backend.

## Included
- Play Store-style launcher
- Instagram-style demo feed and stories
- Like/save demo interactions
- PWA manifest and service worker

## Limitations
Demo content only. No real accounts, uploads, messaging, notifications, or server storage. Does not use Instagram credentials or private APIs.

## Deploy
Static site. Publish repository root with no build command. Open the HTTPS URL in Chrome on Android and choose Install app / Add to Home screen.
